# 文件逐项说明

## 目录总览

```text
home-evening-dashboard/
  README.md                   仓库首页说明
  离线使用说明.html            项目总览离线版
  THIRD_PARTY.md
  FILES.sha256.json

```

## 前端主要文件

以下路径相对 `www/home-evening`。现成运行目录无需 npm 构建。日常配置只改 `site-config.js`，更换图片或交互时再动相关源文件。

## 三维源码

`model-source/model.js` 是建模入口，导入 Three.js 和同目录模块。`cad-layout.js` 负责示例结构与尺寸；`device-display.js` 负责模拟设备标注；`ceiling-strips.js` 负责灯带；`curtains.js` 负责窗帘；`soft-furnishings.js`、`warm-home.js`、`living-quality.js` 负责局部软装和材质；`render-quality.js` 负责渲染调整。

`index.html` 是模型独立预览页面；`package.json`、`package-lock.json` 用于安装固定的 Three.js 依赖。原始 DWG、含住址的文件名、实景照片和 CAD 原始证据没有打包。源码中的结构坐标保留为示例，不是用户自己住宅的尺寸。

运行目录的 `model.js` 来自本次暮色页已有构建产物；`model-source` 保存相关建模源码供参考和修改。不要假设直接打包源码后能与现成文件逐字相同，修改后须核对模型接口、几何、标记和视角。

## 后端集成

这些源文件不上传 `www`，只在需要时放到 HA 的 `custom_components`。

| 目录/文件组 | 作用 |
| --- | --- |
| 各目录 `manifest.json` | 域名、版本、依赖、配置入口与上游来源 |
| `config_flow.py`、`strings.json`、`translations/` | HA 添加集成及选项界面，不含实际账户配置 |
| 各目录 `__init__.py` | 集成加载、平台转发和清理 |
| 控客 `client.py` | SSH 身份校验、缓存读取、协议登录、设备路由 |
| 控客 `climate.py`、`fan.py`、`entity.py` | 空调、地暖、新风实体及控制合同 |
| 国网 `api.py`、`coordinator.py`、`sensor.py` 等 | 按其来源实现取数、更新与实体；以实际目录文件为准 |
| 萤石 `api.py`、`ysproto.py` | 云端会话和媒体协议 |
| 萤石 `stream.py`、`broadcast.py` | 媒体处理、共享流和按需播放 |
| 萤石 `camera.py`、`stream_view.py` | HA 摄像头、受控媒体路径和快照 |
| 萤石 `media_source.py`、`cloud_replay.py` | 媒体浏览器与录像播放 |
| 萤石 `decrypt_image.py`、`decrypt_stream.py` | 使用配置的验证码处理加密媒体，不含作者验证码 |
| 和风 `weather.py`、`sensor.py` | 天气与附属传感器 |
| 和风 `heweather/` | 认证材料处理及常量；实际认证材料由用户后端配置 |
| 和风 `monthly_quota.py` | 本地月预算与缓存；首次安装需自己的初始化账本 |

## 配置和工具

`configs/dashboard.yaml` 是两个前端入口的仪表盘；`configuration-dashboard.example.yaml` 示范 YAML 注册；`native-controls.example.yaml` 是纯 HA 原生真实控制；`scripts.example.yaml` 示范后端离家脚本；`template-grid.example.yaml` 是电网桥接的合并入口。

`tools/electricity_bridge.py` 生成电费模板传感器 JSON；`make_weather_quota.py` 只生成首次预算初始化文件；`validate_package.py` 进行白名单、语法、元数据、配置和已知敏感模式检查。工具不包含作者的 SSH 发布和登录逻辑。

`tests/control-actions.test.mjs` 使用内存 HA 替身验证真实控制适配，不控制设备。`FILES.sha256.json` 列出交付文件摘要，用来确认解压完整和日后修改范围；它不包含自身摘要，也不包含用户后来生成的配置和预算文件。

## 没放进来的文件

原 SSH 连接脚本、自动部署脚本、`.storage`、凭据文件、家庭网络配置、原始 DWG、录像、缩略图缓存、真实设备快照、数据库、日志、私钥、供应商验证码和后台登录状态都不在包内。

没有附带整个 HA 的 Python 环境、`node_modules` 或浏览器。后端依赖由 HA 按清单安装，模型开发依赖由用户按需安装。网页的日常运行已经带了打包的三维、HLS 和历法代码。
