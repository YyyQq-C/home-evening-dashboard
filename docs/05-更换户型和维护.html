更换户型和维护

只换自己的二维图

先保留原包不动，复制一份做自己的版本。清晰户型图、已知长度和门窗位置比材质更重要。

把自己的透明俯视图转换为 WebP，替换 www/home-evening/assets/floorplan-textured.webp。这只换图片，不会自动移动设备标记，也不会自动识别房间边界。

接着修改 floorplan-layout.js：先设置设计坐标系尺寸，再逐项调整灯光和空调、地暖、新风锚点。坐标必须与自己的图对应。原示例用 1800×1502 设计坐标，图片像素尺寸不必相同，但显示比例、裁切和锚点换算必须一致。

floorplan.js 还含 LIGHT_ROOMS 和 LIGHT_PROFILES，控制房间裁切与光照范围。换了户型以后，这些区域也要改；否则会出现灯光照到隔壁房间的情况。只有替换图片、不改坐标，不能算换好了户型。

房间分组和设备归属在 state.js、app.js，其中 5 个房间和 11 路模拟灯组属于这个示例。不同户型不能只重命名房间就保证交互正确。新增真实控制入口的 control.devices 独立于这些模拟几何，不依赖示例户型。

修改三维模型

model-source 提供 Three.js 建模源码，不含 CAD 原文件。独立查看时，在该目录安装固定依赖，再启动本机静态服务：

npm ci
python -m http.server 8794 --bind 127.0.0.1

适用于已安装 Node.js/npm 和 Python 3 的开发电脑。npm ci 会联网下载锁定的 Three.js 包并写入本目录 node_modules；Python 命令只提供本机预览，不操作 HA。打开 http://127.0.0.1:8794/ 查看，以 Ctrl+C 结束服务。

模型结构主要在 cad-layout.js，家具和渲染还涉及 model.js 及多个细化模块。修改尺寸时同时检查地面、墙、门洞、窗台、柜体与家具，不能把图纸里所有尺寸当作同一种边界。

想回到暮色页运行，需要把建模入口及 Three.js 依赖重新打包成 ES module，再更新 www/home-evening/model.js。可以在自己的开发环境使用 esbuild 等工具打包，但要保留已有许可。独立预览里导出的 GLB 并不能直接替换当前这个 JavaScript 文件：当前适配器还依赖场景、灯组、设备标记等接口。

当前 model-adapter.js 至少会读取 window.modelPreview 的 groups、scene、model、camera、controls、renderer、render，以及设备标注与原模型其他约定。通用 GLB 查看器没有这些接口，若想改成加载自己的 GLB，需要另写适配器。

保留首次加载的像素预算：原暮色构建会把模型初始化的 renderer.setPixelRatio(...) 改成读取 window.eveningRenderRatio。重新打包后若恢复为固定高倍率，平板可能先分配过大的渲染缓冲区。

先在独立模型里校对结构、材质、缩放和灯组，再检查暮色页的三维加载、2D 切换、房间展开与视角。最后才能做真实平板检查。桌面浏览器看到图，不代表低内存 WebView 长时间稳定。

图像生成能帮什么

材质增强适合在结构校对后做，提示词可以限制“不改房间轮廓、家具位置和门洞”，但工具不保证精确保持。生成结果应重新对照尺寸和原图。它不会生成 HA 实体，也不会自动把墙和房间变成可交互三维几何。

平面图不必等三维完全做完：用 Sweet Home 3D 等工具按尺寸画结构、摆家具、导出俯视图，再配置 HA 图片元素也是一条独立路线。该路线不会自动获得本包的 Three.js 灯光和标记接口。

发布、升级和回退

  1. 备份自己当前的前端目录、site-config.js 和仪表盘配置。
  2. 解压新包到另一个临时目录，查看说明和文件摘要。
  3. 对比自己的配置与示例，保留自己的实体和后续修改。不要直接用默认空映射覆盖现有配置。
  4. 首先保持真实控制入口只读，确认静态资源、脚本、模型和读数。
  5. 需要实控时再显式开启 live，按单设备顺序验证。
  6. 失败时回到上一份完整前端和配置，不覆盖其他仪表盘。后端集成升级另按对应项目的迁移流程处理。

FILES.sha256.json 描述发行时的文件摘要。自己填写实体后，site-config.js 的摘要自然变化；检查工具不会把用户的合法配置变化自动当成攻击或替你回写文件。

常见问题

表现 优先检查
页面空白 /local/ 映射、脚本 MIME、文件是否完整，不能用 file:// 双击运行应用
页面显示但所有设备不可用 是否从 HA 仪表盘同源 iframe 打开；实体是否填写准确；当前账号是否有权限
实控按钮全灰 默认只读、实体未配置、设备离线或正在等待响应
空调开机被拒绝 onMode 是否自己填写，是否在实体支持列表中
温度无法提交 范围、步长、实体可用性；缺少元数据不会猜测范围
风速选项为空 后端没有暴露该类风速，不代表前端坏了
服务已受理，状态没变化 原厂缓存延迟、设备没有执行、集成异常；区分服务响应、状态和物理效果
模型灯变了，家里灯没变 原展示页仍为模拟；真实控制是 control.html
天气附属字段缺失 weather.sensors 的字段映射、位置、单位和数据可用性
天气预算阻止请求 是否首次使用自己的实际月份和已用次数初始化；已有账本不能重置
电费卡片没内容 先看国网原始实体，再看桥接实体属性，最后查卡片
摄像头只有静态图 缩略图与实时流不同；先在原生详情验证播放
SD 回放不可用 后端版本、录像选项、序列号、媒体浏览器和浏览器播放分别检查
修改配置仍是旧内容 返回的实际模块内容、浏览器缓存和同名目录；不要反复重启设备
